📖解説

5-A. データ抽出の基本手順

  1. Chrome WebDriver でページを開く
  2. 「ブラウザー自動化」→「Web データ抽出」→「Web ページからデータを抽出する」アクションを追加
  3. ライブ Web ヘルパーが起動したら、取得したいテーブル上で右クリックし、以下のどちらかを選ぶ：
    • 「要素の値を抽出」…会社名や金額など一つの値だけ取得したいとき
    • 「HTMLテーブル全体を抽出する」…サイト内の表をまるごと取得したいとき
  4. 取得結果は変数に格納される（既定名：DataFromWebPage）。HTML テーブル抽出を選んだ場合はデータテーブル型変数に格納される。
  5. 変数名は「DataFromWebPage」のままにせず、「StaffList」など内容がわかる名前に変更する習慣を

5-B. ページネーション（複数ページの走破）

「次へ」などのページャーボタンを右クリックし、「要素をページャーとして設定」を選択するだけで、PAD が自動でページ送りをしてくれます。

※ ページネーション処理を「条件付きで終端まで走破する」高度なパターンは 第6回（制御構造） で LABEL ＋ GOTO と組み合わせて扱います。

🛠️ ハンズオン課題②：customer.html の得意先一覧（複数ページ）を全件取得するフローを作ってみましょう。

5-C-①. <object> / <iframe> 埋め込み UI の限界（必読）

見た目はポップアップウィンドウなのに、その中身がこっそり「別のページ」を読み込んでいる作りになっているサイトがあります。こういう UI で PAD の「UI 要素の追加」を使おうとしても、ポップアップの外側の枠しか認識されず、中の入力欄やボタンは取得できません。
このデモサイトでも、左サイドバーの「スタッフ検索」や「スタッフ追加」を開いて PAD の UI 要素ピッカーを使おうとすると、ポップアップ内に赤い枠が表示されません。これがまさにそのパターンです。
🛠️ ハンズオン課題③：staff-search-popup.html に PAD の要素取得をかけ、「中の入力欄が取れない」現象を実際に体験してみましょう。

5-C-②. 解決策 〜埋め込みページの URL を特定して直接ナビゲート〜

ポップアップ内を操作する代わりに、その中身として読み込まれているページの URL そのものへ PAD から直接ナビゲートします。URL さえわかれば操作の再現は完了です。

  1. F12 を押して開発者ツールを開く
  2. 開発者ツールを開いた状態でポップアップを開くメニューをクリック
  3. Elements タブを開くと、一番下に新しい文字列（ポップアップの HTML ソース）が追加される
  4. その文字列をダブルクリックすると、読み込まれているページのフル URL が確認できる
使うアクション：「Web ページに移動する」。確認した URL をそのまま指定するだけで、ポップアップを開かずに同じ画面にジャンプできます。

5-C-③. URL パラメータを動的に組み立てる

業務サイトでは検索結果ページの URL にパラメータが付いていることが多く、入力フォームを操作する代わりに URL を組み立てて直接遷移する手法も使えます。

// ポップアップを操作する代わりに： dept = "営業部" role = "主任" url = "staff-list.html?dept=" + dept + "&role=" + role → Web ページに移動する: %url% （= staff-list.html?dept=営業部&role=主任 に直接ナビゲート）
  • ?page=2 ページ番号の指定
  • ?search=山田 検索キーワード
  • ?dept=営業部&role=主任 複数条件（& で連結）
  • ?id=ST001 特定レコードの直接参照
🛠️ ハンズオン課題④：下のシミュレーターで部署・役職を選び、生成された URL を確認。同じパターンを PAD の「Web ページに移動する」アクションに組み込んでみましょう。

5-C-④. インタラクティブデモ：URL 組み立てシミュレーター

ポップアップと同じ選択肢で部署と役職を選ぶと、生成される URL がリアルタイムに表示されます。「このURLを開く」を押すと実際に staff-list.html に遷移し、ポップアップを使った場合と同じ結果になることが体感できます。

❓よくある詰まりと FAQ

Q1. ポップアップ内の要素がいくら待っても取れない
<object>/<iframe> 埋め込みの可能性大。F12 で確認し、URL 直接ナビゲートに切り替える。
Q2. 抽出したデータテーブルの列名が文字化けする
サイト側のヘッダ行が日本語の場合、Excel に書き出した際に文字化けすることがあります。Excel.LaunchExcel で開く際の Encoding を UTF-8 にすると改善することが多いです。
