🎯到達目標

  • Excel を起動し、特定シートを選択し、セルに書き込み、保存できる
  • 既存マクロを呼び出せる（Excel マクロの実行）
  • ファイルパスを変数化して、同じフローを複数の Excel で使い回せる
  • 現在の日時を取得 ＋ 日時をテキストに変換 で yyyyMMdd_HHmmss 形式の文字列を作れる
  • 環境変数を取得 で USERNAME を取得し、デスクトップ直下の動的パスを組み立てられる
  • フォルダーの作成 で実行ごとに日時名サブフォルダを作成できる
  • ファイルのコピー でテンプレ（.xlsm）を複製し、ファイルの名前を変更する で「氏名_ID」へ改名できる

🪜事前準備

📖解説

3-A. Excel 自動化の基本3アクション

  1. Excel の起動：Excel を起動／既存ファイルを開く
  2. Excel ワークシートに書き込む：指定セル（例：B2）に値を書き込む
  3. Excel を閉じる（保存して閉じる）：保存して閉じる
セル指定は列＋行（B2 / A10 など）または列番号＋行番号（2,2 など）どちらでも OK。最終演習では氏名を B2、出力日時を B10 に書き込みます。
🛠️ ハンズオン課題①：テンプレ Excel（スタッフ情報_テンプレート.xlsm）を開き、B2 セルに「山田 太郎」と書き込んで別名保存するフローを作ってみましょう。

3-B. マクロを呼び出す（Excel マクロの実行）

テンプレ Excel に組み込まれているマクロを PAD から呼び出せます。最終演習では「空白削除」マクロを呼び出して、プロフィールシートの不要な空白行を一括除去します。

⚠️ .xlsm（マクロ有効ブック）であることを必ず確認。.xlsx ではマクロが動きません。
🛠️ ハンズオン課題②：課題①のフローに「空白削除」マクロを実行するアクションを追加してみましょう。

3-C. 日時整形（現在の日時 ＋ 日時をテキストに変換）

「日時フォルダを作る」「ファイル名に日時を入れる」ためには、現在日時を取得して文字列に整形する必要があります。

  1. 現在の日時を取得：現在日時を取得（DateTime 型）
  2. 日時をテキストに変換：カスタム書式 yyyyMMdd_HHmmss で文字列化（例：20260518_143025）

3-D. 動的フォルダ生成（環境変数＋フォルダーの作成）

  1. 環境変数を取得：USERNAME を取得（→ C:\Users\(自分)\Desktop を動的に組み立てる）
  2. フォルダーの作成：上記パス直下に「日時フォルダ」を作成
出力フォルダ = "C:\Users\" + %UserName% + "\Desktop\" + %現在の日時_テキスト値%

3-E. テンプレ複製＋改名（ファイルのコピー / ファイルの名前を変更する）

  1. ファイルのコピー：テンプレ スタッフ情報_テンプレート.xlsm を出力フォルダにコピー
  2. ファイルの名前を変更する：コピー後のファイル名を「氏名_ID.xlsm」に改名
🛠️ ハンズオン課題③（最終課題）：「現在日時取得 → yyyyMMdd_HHmmss 整形 → デスクトップ直下に日時フォルダ作成 → テンプレ.xlsm コピー → 氏名_ID に改名 → 開く → B2に氏名／B10に日時を書き込み → 空白削除マクロ実行 → 保存して閉じる」を1本のフローで実装してみましょう。

❓よくある詰まりと FAQ

Q1. マクロを実行しても何も起こらない
ファイル拡張子が .xlsm であること、マクロ名が完全一致していること、Excel の「マクロを有効にする」が許可されていることを確認してください。
Q2. 日時フォーマットが思ったとおりにならない
月は MM、分は mm（小文字）です。秒は ss。yyyyMMdd_HHmmss が標準形。
Q3. File.Copy で「ファイルが存在します」エラー
「ファイルが存在する場合」の挙動を「上書き」に設定するか、出力フォルダを毎回日時で変えてください（最終演習では日時フォルダで自然に解決します）。
