📖解説

1-A. Power Automate for Desktop をインストールする

Windows 11 には Power Automate for Desktop が標準搭載されています。
まずはスタートメニューから起動して、アプリケーションが存在するかを確認しましょう。

  1. スタートメニュー（左下の Windows ロゴ）をクリックする
  2. 検索バーに「Power Automate」と入力して検索する
  3. 「Power Automate」（Microsoft Corporation 製）が表示されたら、それをクリックして起動する
  4. Microsoft アカウント（職場・学校アカウント）でサインインする
💡 アプリが見つからない場合
Microsoft Store を開き「Power Automate」で検索 →「Power Automate」（Microsoft Corporation 製）の「インストール」をクリックしてください。
ハンズオン課題①：PAD で新しいフローを作成し、「Webページを開く」アクションを使って デモサイトトップページ を「操作方法 = ブラウザー拡張機能」で開いてみましょう。

1-B-①. ChromeDriver vs 標準起動 〜どちらを使うべき？〜

PAD には Chrome を起動する方法が2種類あります。本研修では Chrome WebDriver起動 を必修として使います。その理由をここで理解しましょう。

項目 ブラウザー拡張機能 Chrome WebDriver起動
PADのアクション名新しい Chrome を起動する新しい Chrome を起動する
仕組みすでに起動している Chrome に「割り込む」PAD が Chrome を子プロセスとして完全制御
セットアップ不要ChromeDriver の配置が必要
業務サイトでの安定性⚠️ サイトによって要素が取れないことがある✅ 業務サイトでも安定して動作しやすい
本研修での推奨△ 学習初期のみ◎ 必須（第4回以降）
📌 アクション名は同じ、設定で切り替える： PAD ではどちらも 「新しい Chrome を起動する」 という同じアクションです。設定画面の 「操作方法」 プルダウンで「ブラウザー拡張機能」と「Webdriver」を切り替えます。
たとえるなら： 標準起動は「すでに走っている車に後から乗り込む」方式。WebDriver起動は「PAD が運転席に最初から座る」方式。後者のほうが業務サイトで安定して走れます。
ハンズオン課題②：課題①で作ったフローの起動アクション設定を開き、「操作方法 = Webdriver」に切り替えて再実行してみましょう（次の 1-B-② で ChromeDriver を配置すると正常に動きます）。

1-B-②. ChromeDriver のインストール手順（5ステップ）

  1. 手順1：Chrome のバージョンを確認する
    Chrome を開き、アドレスバーに chrome://settings/help と入力する。
    バージョン番号（例: 138.0.7204.169）をメモする。
  2. 手順2：対応する ChromeDriver をダウンロードする
    公式 ChromeDriver ページ（ https://developer.chrome.com/docs/chromedriver ）にアクセスする。
    Chrome ブラウザのバージョンと一致するバージョンを選択（通常、最初の3つの数字が一致していれば OK）。
    win-x64 アーキテクチャ用の ZIP をダウンロード。
  3. 手順3：ダウンロードした ZIP ファイルを解凍する
    ZIP ファイル（例：chromedriver-win64.zip）を右クリック →「すべて展開」を選択。展開先は既定のままで OK。chromedriver-win64\chromedriver.exe ができる。
  4. 手順4：Power Automate Desktop 用のフォルダを作成する
    エクスプローラーを開き、アドレスバーに以下を貼り付けて Enter：
    %LOCALAPPDATA%\Microsoft\Power Automate Desktop
    フォルダー内で右クリック →「新規作成」→「フォルダー」を選択。
    フォルダー名を WebDrivers にする（大文字・小文字を正確に）。
  5. 手順5：chromedriver.exe を配置する
    手順3で解凍したフォルダから chromedriver.exe をコピー → 手順4で作成した WebDrivers フォルダに貼り付ける。

    最終的なフォルダー構成：
    AppData └ Local └ Microsoft └ Power Automate Desktop └ WebDrivers └ chromedriver.exe
ハンズオン課題③：「メッセージを表示する」アクションを課題①／②のフローに連結し、「業務効率化、始まる！」と表示してみましょう。WebDriver 起動で動くことを確認してください。

1-B-③. バージョン不一致に注意

⚠️ 注意： Chrome は自動更新されます。ChromeDriver のバージョンが古くなると、ある日突然フローが動かなくなります。
月に1回、Chrome のバージョンを確認して ChromeDriver を更新する運用を推奨します。
典型的な症状：「ChromeDriver と Chrome のバージョンが一致しません」というエラーメッセージ。

📝 3行まとめ（1-B）

  1. PAD の「新しい Chrome を起動する」アクションは「操作方法」プルダウンで 標準起動と WebDriver起動を切り替える。業務サイト対応では後者が本命。
  2. ChromeDriver は %LOCALAPPDATA%\Microsoft\Power Automate Desktop\WebDrivers\chromedriver.exe に配置すれば PAD が自動で読み込んでくれる。
  3. Chrome の自動更新でバージョン乖離が起きるため、月次で点検する運用が必要。

❓よくある詰まりと FAQ

Q1. スタートメニューで検索しても「Power Automate」が出てこない
Microsoft Store を開き「Power Automate」で検索 →「Power Automate」（Microsoft Corporation 製）の「インストール」をクリックしてください。
Q2. ChromeDriver を入れたのに「バージョンが一致しません」エラーが出る
chrome://settings/help で Chrome の最新バージョン番号を再確認し、最初の3桁（例: 138.0.7204）が一致する ChromeDriver を再ダウンロードして上書き配置してください。
Q3. WebDrivers フォルダを作ったのに PAD が認識しない
フォルダ名のスペルを確認してください（WebDrivers、大文字小文字を含めて正確に）。配置先パスが %LOCALAPPDATA%\Microsoft\Power Automate Desktop\WebDrivers\ であることを再確認。
Q4. 「操作方法」プルダウンに「Webdriver」が出てこない
PAD のバージョンが古い可能性があります。Microsoft Store から最新版に更新してください。
