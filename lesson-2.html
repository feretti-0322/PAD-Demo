📖解説

2-A-①. 変数 ＝ データを入れておく「箱」

変数は、数字や文字などのデータを一時的に保存しておく場所です。箱に名前をつけて、中に好きなデータを入れておけます。

担当者名
田中さん
注文数
50
完了フラグ
True
箱には数字・文字・Yes/No（True/False）などいろんな種類のデータを入れられます。
PAD では %変数名% と書くことで、箱の中身をプログラムの中で使えます。

2-A-②. なぜ変数を使うの？

😰 変数を使わないと…

担当者が変わるたびにプログラム内の「田中さん」を全部探して書き直す必要があります。書き忘れるとバグの原因に！

メール送信("田中さんへ") レポート作成("田中さん担当") 通知送信("田中さん確認済")

😊 変数を使うと！

「担当者名」という箱に名前を入れておけば、箱の中身を1か所変えるだけでプログラム全体に反映されます。

担当者名 = "田中さん" ↓ メール送信(%担当者名%へ) レポート作成(%担当者名%担当) 通知送信(%担当者名%確認済)

2-A-③. 変数には「わかりやすい名前」をつけよう

何を入れる箱？NG な名前OK な名前
社員の名前NGa / data1OK社員名 / EmployeeName
今月の売上合計NGx / numOK今月売上合計 / TotalSales
処理が終わったかどうかNGflag / bOK処理完了フラグ / IsDone
変数名は「日本語でも OK」です。業務系の人には日本語名のほうが直感的で誤読が減ります。
🛠️ ハンズオン課題①：以下の流れで、現在の日時を取得して表示するフローを作ってみましょう。
  • 「現在の日時を取得」アクションで日時を取得（生成される変数名は分かりやすく 現在時刻 に変更する）
  • 「メッセージを表示する」で 「現在の日時は %現在時刻% です」 と表示させる

2-B-①. データテーブル 〜Excel の表を PAD の中で扱う変数〜

スクレイピング結果や Excel から表全体を抽出した場合は、DataTable 型の変数に格納されます。行と列を持つ表形式のデータを、PAD の中で自在に操作できます。

  • 作成・読み込み：スクレイピング結果の格納／Excel ワークシートからの読み込み
  • 行の追加：「データテーブルに行を挿入」アクションで1行ずつ追加
  • フィルタ・検索：「フィルターデータテーブル」で条件に合う行だけ抽出
  • 書き出し：「Excel ワークシートに書き込む」で DataTable をシートに反映

2-B-②. DataTable の値を取り出す（インタラクティブデモ）

DataTable の特定の値を取り出すには、変数名の後ろに [] を使って「行番号」と「列番号 or 列名」を指定します。DataTable の添字は 0 から数え始めることに注意してください。

StaffList[0]['氏名'] // 1行目の氏名列 StaffList[0][2] // 1行目の3列目（インデックス指定） CurrentItem['部署'] // FOR EACH 内での現在行の部署列
列名を使った指定（CurrentItem['氏名']）は、列の順番が変わってもフローが壊れません。インデックスだけ（CurrentItem[0]）はシンプルですが、サイト改修に弱いので注意。

2-C. 直書きデータテーブル ＋ 列リスト化 ＋ 選択ダイアログ（最終演習 Main の縮小版）

最終演習の Main では、「部署 × 役職」マスターをフローに直書きし、列を取り出してユーザーに選ばせる仕組みを作ります。

  1. 新しいデータテーブルを作成：ヘッダ「部署」「役職」を持つデータテーブルを直書きで作る
  2. データテーブル列をリストに取得：「部署」列だけを取り出してリスト化
  3. リストから選択ダイアログを表示：ユーザーにリストから選ばせ、選択結果を変数に格納
  4. 同じ流れで「役職」も選ばせる
🛠️ ハンズオン課題③：「部署×役職」マスターを直書きデータテーブルで作成 → 部署列をリスト化 → 選択ダイアログで選ばせる → 同じく役職も選ばせる → 選択結果を「メッセージを表示する」で表示するフローを実装してみましょう。
🛠️ ハンズオン課題④（最終課題）：派遣スタッフ名（変数）＋部署（変数）＋入社日（変数）を組み合わせてプロフィール文を生成するフローを作ってみましょう。
例：「%スタッフ名% さんは %部署% に %入社日% 入社」というメッセージを表示。

❓よくある詰まりと FAQ

Q1. 変数名に日本語を入れたら動かない
PAD は変数名に日本語 OK ですが、参照時は %変数名% のように半角 % で囲む必要があります。全角 ％ になっていないか確認してください。
